---
title: Connect Agent to Fabric
description: Set Houdry server URL so chat uses your GPUs.
---

Houdry Agent will not use the plant GPUs until it is aimed at Fabric.

1. Confirm `houdry serve --listen 0.0.0.0:8080` is running.
2. Open Agent → **Houdry server URL**.
3. Same machine: `https://127.0.0.1:8080/v1`.
4. Another machine: `https://HOST:8080/v1` (must include `/v1`).
5. Model: `auto`.
6. Optional key `houdry` if `serve` was started with `--token`.
7. Connect. Send “Say hello.” You should get a local reply.

If several control planes answer, pick the one for this plant. Isolated guest Wi-Fi: skip discovery and paste the URL. If TLS fails, trust `~/.houdry/server/pki/root_ca.crt` from the serve host.

See [LAN and fabric URL](/docs/configuration/remote-access).
