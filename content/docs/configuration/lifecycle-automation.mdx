---
title: Scheduled jobs
description: Recurring work in Houdry Agent, still on the fabric.
---

Houdry Agent can keep **scheduled jobs** (cron-style) in the desktop app. Those jobs still call the same fabric `/v1` endpoint. They do not open a cloud runner.

- Create the schedule in Agent.
- Keep Fabric (`serve` + at least one `gpu register`) up at the time the job fires.
- Point the job at Knowledge that already exists locally.

If a scheduled run fails, check Fabric first (`houdry discover`, GPU still READY), then Agent’s Houdry server URL.
