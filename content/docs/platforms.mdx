## GPU workstation

Install [Fabric from GitHub Releases](/docs/installation). NVIDIA, AMD, and platform inventory are reported by `houdry gpu detect`. A workstation without a discrete GPU can still run `houdry serve` as the control plane; another box registers as compute.

## Desk

Install [Houdry Agent](/docs/installation). It only needs to reach `https://HOST:8080/v1` on the LAN (or localhost). It does not need a GPU.

## Discovery

`houdry serve` announces on Wi-Fi. Agent and `houdry gpu register` browse for that announce. Isolated guest networks will not see it. Paste `https://HOST:8080/v1` in Agent instead.

## Data locations

| Product | Default home |
| --- | --- |
| Fabric | `~/.houdry` (`HOODRY_HOME`) |
| Agent (Linux/macOS) | `~/.houdry-agent` |
| Agent (Windows) | `%LOCALAPPDATA%\houdry-agent` |
