---
title: Agent on the desk
description: What Houdry Agent owns versus what Fabric owns.
---

Houdry Agent is the desktop product. It is not a plugin marketplace and it does not bundle third-party coding-agent harnesses.

| On Agent | On Fabric |
| --- | --- |
| Chat UI, sessions, knowledge, standing rules, scheduled jobs, local tools | GPUs, Ollama, routing, `/v1/chat/completions` |

Start here: [Houdry Agent](/docs/dashboard). To add compute, [add GPU workstations](/docs/guides/add-gpu-workstations).
