These assume [Quickstart](/docs/quickstart) already works: Fabric serving, a GPU registered, Agent connected, knowledge loaded.

## Approval note from an inspection PDF

1. Add `01_Inspection_Report_E204.pdf` and the matching SOP to **Knowledge base**.
2. New session. Prompt:

```text
Using only the E-204 inspection report and its SOP, draft an approval note.
Quote findings with page or section. Do not add equipment that is not in the report.
```

3. Save the file Agent produces. Check that every number appears in the source PDF.

## Tag register from a drawing

Attach or index a P&ID / scan. Prompt:

```text
Extract equipment tags and titles from this drawing into a table.
Leave blank where the title block is unreadable. Do not guess.
```

Fabric should route this to a vision-capable model on a READY node.

## Calculation in a sandbox

```text
From the quoted design pressure in the spec, compute the test pressure per the SOP.
Show the formula and the values you used. Stop if a required input is missing.
```

## If the answer looks like a public chatbot

Agent is not pointed at Fabric. Recheck **Houdry server URL** (`…:8080/v1`) and that `houdry gpu register` is still running.
